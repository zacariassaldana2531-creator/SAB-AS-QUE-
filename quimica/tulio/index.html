Tulio

Metal de las tierras raras gris plateado. Es la menos abundante de las tierras raras naturales.

Tipo de afirmación: Hecho comprobado

Para qué sirve y en qué se usa

  • El tulio-169 irradiado sirve como fuente de radiación para equipos portátiles de rayos X
  • Ferritas para equipos de microondas
  • Láseres de fibra
