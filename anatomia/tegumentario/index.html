Sistema tegumentario

La piel, el pelo y las uñas: la barrera del cuerpo con el exterior.

La piel es el órgano principal de este sistema. Junto con el pelo, las uñas y glándulas como las sudoríparas, forma el sistema tegumentario.

Para qué sirve

  • Protege contra golpes, microbios y pérdida de agua.
  • Regula la temperatura mediante el sudor.
  • Permite sentir el tacto, la presión, el calor o el dolor.
  • Produce vitamina D con la luz solar.

¿Sabías que…?

  • El color de la piel depende sobre todo de un pigmento llamado melanina.
  • La melanina también ayuda a proteger el cuerpo de las quemaduras solares.

Órganos de este sistema

  • Piel
  • Cabello y vello
  • Uñas
